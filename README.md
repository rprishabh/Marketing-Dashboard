# Marketing Mission Control 🛰️

A vibrant, high-performance Growth Ops control tower built with Next.js (App Router), Tailwind CSS, and Recharts. Instantly toggle between B2B, B2C, and D2C segment classes to monitor dynamic KPI grids, 30-day Recharts performance trends, active campaign registries, and live AI automation streams in a high-fidelity glassmorphism HUD.

*Currently populated with realistic simulated mock data, the dashboard is architected to seamlessly connect to live APIs—including **Google Analytics 4 (GA4)**, **HubSpot CRM**, **Google & Meta Ads**, and custom **AI Workflow Automation APIs**—to stream real-time operational growth metrics.*

---

## ⚡ Key Features

- **Segment Class Selector**: Instantly swap between B2B, B2C, and D2C metrics in a unified top navigation HUD.
- **Dynamic KPI Grid**: Automatically displays relevant marketing metrics:
  - **B2B**: Total MQLs, SQL Conversion Rate, Pipeline Velocity, Blended CAC.
  - **B2C**: Daily Active Users (DAU), Cost Per Install (CPI), App Store Conversion Rate, Viral Coefficient.
  - **D2C**: Average Order Value (AOV), Return on Ad Spend (ROAS), Cart Abandonment Rate, Customer Lifetime Value (CLV).
- **Vibrant Accent Themes**: Dynamic styling color variables update automatically based on selection (Violet for B2B, Hot Pink for B2C, Amber for D2C).
- **High-contrast AreaChart**: A custom performance chart plotting 30-day trend lines in glowing neon matrix colors.
- **Live AI Automation Logs**: monospaced scroll-locked terminal stream feeding automated execution logs from active agent nodes.
- **Glassmorphism Panels**: Modern UI layout backed by background mesh grids and neon corner borders.

## 🚀 Getting Started

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/rprishabh/Marketing-Dashboard.git
cd Marketing-Dashboard
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

## ☁️ Deployment on Vercel

The easiest way to deploy this dashboard for free:
1. Push this project to your GitHub repository.
2. Sign in to [Vercel](https://vercel.com/new).
3. Import the `Marketing-Dashboard` repository and click **Deploy**.
